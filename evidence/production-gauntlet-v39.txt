FIVE DEFECTS FIXED (v39.2.0), each with a regression test:
1. foreman takes the kernel-released workspace lock — busy = named
   refusal, exit 2, no actions, no receipt pretense
2. action exceptions are NAMED ("backup-drill failed: File too
   large") and the run stops — the plain-language law applies to
   the agent itself
3. _write_tar_body failures clean their tmp: no corpse, ever
4. ignition speaks a refused run's own reason ("workspace locked:
   another run holds it (kernel releases it if that run died)")
5. `aeos backup` names starvation: "BACKUP REFUSED — the disk would
   not take it" — never a traceback
