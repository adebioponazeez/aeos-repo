WHAT SHIPPED (ADR-052)
================================================================
1. THE LANGUAGE — a NAMED DOT SUBSET: digraph, node [attrs],
   -> chains, subgraph cluster_*, // and # comments, quoted
   strings. Every error a plain-language GraphError with a line
   number — never a SyntaxError traceback (tested: lexer,
   parser, semantics all name their failures).
2. CLUSTERS ARE NESTED HARNESSES: subgraph cluster_build compiles
   to ONE parent task whose subplan is the cluster's nodes —
   the v39.5 recursion, declarative. Cross-level edges attach
   through the parent (no phantom nodes — a real parser bug
   found and fixed during the build); same-cluster edges
   declared at the parent level are placed inside; nesting
   deeper than MAX_SUBPLAN_DEPTH is a NAMED compile error.
3. ROUTING STYLESHEETS: INI sections matched by fnmatch on task
   names (a nested-harness parent also matches its cluster
   name); PER-KEY FALLBACK — each key takes the first matching
   section that defines it, [*] is the fallback. Keys: model,
   agent, max_attempts.
4. THE SAFETY LAW, COMPILE-ENFORCED: stylesheets route, they
   NEVER declassify. class= on a stylesheet section or an edge
   is a NAMED refusal — classification lives on the node where
   the agent acts; a routing layer that could move classes
   could hide danger. Regression-tested in both places.
5. ZERO NEW TRUST: the compiled graph is the SAME TaskSpec the
   orchestrator runs — governor classifies every task, hooks
   fire at every point (wave/task/subplan through the compiled
   graph — tested), gates grade every envelope. Declarative
   buys ergonomics, not immunity.

HONESTY ABOUT THE PROCESS
================================================================
- Found and fixed during the build: cross-level edges made the
  PARSER create phantom empty nodes in the parent graph (the
  "node 'core' has no agent" misfire) — edges are now stored raw
  and resolved at compile time.
- Found and fixed: dependency direction inverted in the first
  compile (a -> b must mean b depends on a) — caught by the
  direction test, not by luck.
- Routing semantics sharpened twice from the shipped example:
  last-match-wins -> first-match-wins -> PER-KEY FALLBACK (the
  CSS habit), and cluster names now match their parent tasks.
- The count fixed point: scribe counts passed+failed, so the
  truthful claim is the green-state total (565), reached and
  verified stable.
